# PC MATE — установка и настройка

Инструкция для человека, а не для разработчика. Цель — за 10 минут дойти от
пустого компьютера до первого удалённого включения.

---

## Что понадобится

* Компьютер с Windows 10 или 11, подключённый к роутеру **кабелем**
  (по Wi-Fi включение почти наверняка не заработает — об этом ниже);
* телефон с Android 8 и новее;
* 10 минут.

Необязательно, но нужно для управления **не из дома**:

* сервер (любой VPS за 200–300 ₽/мес);
* мост пробуждения — ESP32 (~500 ₽) или Raspberry Pi, который всегда включён.

---

## Шаг 1. Установить агента на компьютер

1. Запустите `PcMate-Setup-1.0.0.exe` и подтвердите запрос прав администратора.
2. Установщик сам:
   * поставит службу PC MATE и помощник в трее,
   * добавит правило брандмауэра для домашней сети,
   * включит гибернацию и разрешит таймеры пробуждения.
3. После установки откроются два окна: **QR-код** и **мастер готовности**.

> Если установщика нет, из каталога `agent` в PowerShell **от администратора**:
> `./build.ps1` затем `./install.ps1`.

---

## Шаг 2. Пройти мастер готовности

Мастер проверяет 12 вещей. Возле каждой — цветной значок:

* **✓ зелёный** — всё в порядке;
* **! жёлтый** — работать будет, но есть нюанс;
* **✕ красный** — эта часть не заработает.

Там, где есть кнопка **«Исправить»**, нажмите её — мастер всё сделает сам.

Что мастер проверяет и почему это важно:

| Проверка | Зачем |
|---|---|
| Гибернация включена | Лучший режим: ПК просыпается по таймеру и сохраняет открытые программы |
| Режимы сна S3/S4 | Из них компьютер вообще способен просыпаться |
| Таймеры пробуждения разрешены | Без этого расписание «включить» не сработает |
| Быстрый запуск отключён | Мешает включению из полностью выключенного состояния |
| Сетевая карта может будить ПК | Иначе магический пакет будет проигнорирован |
| Пробуждение по магическому пакету | Собственно, функция Wake-on-LAN в драйвере |
| Подключение по кабелю | Wake-on-WLAN на настольных ПК почти не работает |
| MAC и локальный IP | Без них телефону некуда слать пакет |
| Постоянный IP | Чтобы телефон находил компьютер после перезагрузки роутера |
| Wake-on-LAN в BIOS | Проверяется только тестовым пробуждением |
| Связь с сервером | Нужна для управления не из дома |
| Автовход | Нужен только при включении из полного выключения |

**Красный пункт «Wake-on-LAN в BIOS»** — единственное, что нельзя починить из
программы. Перезагрузите компьютер, войдите в BIOS/UEFI (обычно Del или F2 при
включении) и найдите пункт с названием вроде **Wake on LAN**, **Power on by
PCI-E**, **Resume by LAN**. Включите его. Если есть **ErP** или **Deep Sleep** —
выключите: они обесточивают сетевую карту.

---

## Шаг 3. Подключить телефон

1. Установите приложение PC MATE на телефон.
2. Нажмите **«Подключить компьютер»** и наведите камеру на QR-код с экрана ПК.
3. Телефон и компьютер покажут одинаковый **отпечаток ключа** вида
   `K7M2-9QX4-11BC-7D0E-2FG3-HJ5K`. Сверьте их — это защита от подмены.

Готово. Из домашнего Wi-Fi уже работают: выключение, сон, гибернация,
блокировка и сценарии.

---

## Шаг 4. Проверить, что включение работает

В мастере готовности нажмите **«Тест Wake-on-LAN»**:

1. Компьютер уснёт на 2 минуты.
2. Пока он спит, нажмите в приложении большую кнопку **«Включить»**
   (телефон должен быть в домашнем Wi-Fi).
3. Компьютер должен проснуться и сообщить результат теста.

Отдельно стоит проверить **«Тест таймера пробуждения»** — компьютер уснёт и
должен проснуться сам через две минуты. Этот способ работает вообще без сети и
используется для расписаний.

Если тест не прошёл — [решение проблем](troubleshooting.md).

## Шаг 5 (по желанию). Управление не из дома

Нужны две вещи: **сервер** (передаёт команды) и **мост** (включает компьютер).

### Сервер

На любом VPS с Docker:

```bash
git clone <репозиторий> && cd PcMATE/server
cp .env.example .env
nano .env            # впишите PCMATE_DOMAIN=relay.ваш-домен.ru
docker compose up -d
```

Домен должен указывать на IP сервера — сертификат Caddy получит сам.

Затем на компьютере: значок PC MATE в трее → **Настройки** →
**Сервер-ретранслятор** → `wss://relay.ваш-домен.ru` → **Сохранить**.

В приложении на телефоне заново отсканируйте QR-код: теперь в нём есть адрес
сервера.

### Мост пробуждения

Узнайте идентификатор компьютера: в приложении **Ещё → Диагностика** →
«Идентификатор компьютера».

**Вариант А — Raspberry Pi или любой Linux, который всегда включён:**

```bash
cd PcMATE/bridge/linux
sudo ./install.sh wss://relay.ваш-домен.ru <идентификатор-компьютера>
```

**Вариант Б — ESP32 (~500 ₽):**

```bash
cd PcMATE/bridge/esp32
pio run -t upload
```

После прошивки плата поднимет точку доступа **«PC MATE Bridge»**
(пароль `pcmate123`). Подключитесь к ней телефоном, откроется страница
настройки: укажите домашний Wi-Fi, адрес сервера и идентификатор компьютера.
Дальше воткните плату в любую зарядку — она будет работать годами.

## Шаг 6. Сценарии и расписания

**Сценарий** — цепочка действий на компьютере.

1. В приложении: **Сценарии → Новый сценарий**.
2. Дайте имя, например «Вечер».
3. **Выбрать программу** — телефон запросит у компьютера список установленных
   программ, путь вводить не нужно.
4. Добавьте паузу, сайт, громкость, уведомление — в любом порядке.
5. Сохраните и нажмите **«Запустить»**.

Пример сценария «Вечер»:

```
1. Запустить Steam
2. Пауза 10 секунд
3. Запустить OBS Studio
4. Открыть сайт youtube.com
5. Громкость 40 %
6. Уведомление на телефон: «ПК готов 👍»
```

**Расписание** — то же самое по часам.

* **Расписания → Новое расписание**;
* действие «Включить», время 23:00, дни Пн–Пт;
* выберите сценарий, который выполнится после пробуждения.

Значок ⏳ рядом с расписанием означает, что компьютер ещё не завёл таймер
(например, сейчас выключен). Как только он выйдет на связь, значок сменится на ✓.

**«Буду через N минут»** — разовый вариант того же: компьютер проснётся и
подготовится к вашему приходу.

## Куда что устанавливается

| Что | Где |
|---|---|
| Программа | `C:\Program Files\PC MATE` |
| Настройки, ключи, сценарии, расписания | `C:\ProgramData\PcMate` |
| Журналы | `C:\ProgramData\PcMate\logs` |
| Задачи пробуждения | Планировщик заданий → папка «PC MATE» |
| Служба | `PcMateAgent` (services.msc) |

---

## Удаление

Панель управления → Программы → PC MATE → Удалить.

Установщик спросит, удалять ли настройки и сопряжения. Если планируете ставить
заново — ответьте «Нет», и все сценарии и расписания сохранятся.
