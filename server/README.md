# Сервер-ретранслятор PC MATE

Передаёт зашифрованные команды между телефоном, компьютером и мостом
пробуждения. Содержимое команд не расшифровывает и расшифровать не может.

---

## Зачем он нужен

Без сервера PC MATE работает только в домашней сети: телефон находит компьютер
по локальному адресу и разговаривает с ним напрямую.

Сервер нужен, чтобы управлять компьютером **откуда угодно**, и при этом
**не открывать порты на домашнем роутере**: и компьютер, и мост сами
устанавливают исходящее соединение с сервером.

---

## Развёртывание

Любой VPS с Docker, 1 ГБ памяти достаточно.

```bash
git clone <репозиторий>
cd PcMATE/server

cp .env.example .env
nano .env                 # PCMATE_DOMAIN=relay.ваш-домен.ru

docker compose up -d
```

Caddy получит сертификат Let's Encrypt автоматически — нужно только, чтобы
A-запись домена указывала на этот сервер.

Проверка:

```bash
curl https://relay.ваш-домен.ru/api/v1/health
# {"ok":true,"product":"PC MATE","version":"1.0.0","protocol":1,...}
```

Дальше на компьютере: трей PC MATE → **Настройки** → **Сервер-ретранслятор** →
`wss://relay.ваш-домен.ru`.

## Настройки (переменные окружения)

| Переменная | По умолчанию | Смысл |
|---|---|---|
| `PCMATE_PORT` | `8080` | порт внутри контейнера |
| `PCMATE_DB` | `./data/pcmate.db` | файл SQLite |
| `PCMATE_LOG_LEVEL` | `info` | `debug`, `info`, `warn`, `error` |
| `PCMATE_ALLOW_REGISTRATION` | `true` | закройте после настройки всех устройств |
| `PCMATE_REGISTRATION_SECRET` | — | общий секрет: без него регистрация отклоняется |
| `PCMATE_PING_INTERVAL_MS` | `30000` | как часто сервер шлёт ping |
| `PCMATE_CONNECTION_TIMEOUT_MS` | `90000` | когда считать устройство отключившимся |
| `PCMATE_PAIR_TIMEOUT_MS` | `20000` | сколько ждать ответа ПК при сопряжении |
| `PCMATE_EVENTS_PER_PC` | `500` | глубина истории на один компьютер |
| `PCMATE_RATE_LIMIT_MAX` | `120` | запросов в окно с одного адреса |

Сгенерировать секрет регистрации:

```bash
openssl rand -base64 24
```

## Что сервер знает о вас

**Видит:** какие устройства существуют, какое с каким спарено, когда они были на
связи, их публичные ключи, MAC и локальные IP компьютеров, расписания, короткие
записи истории («компьютер проснулся»), размер и время прохождения команд.

**Не видит:** содержимое команд, ответов и событий — они зашифрованы ключами,
которых у него нет. Даже владелец сервера не может узнать, какие программы вы
запускаете и когда выключаете компьютер по кнопке.

**Не хранит:** ваши пароли (их не существует в системе), приватные ключи,
расшифрованные команды.

## Разработка

```bash
npm install
npm run dev          # tsx watch
npm test             # node:test, 34 теста
npm run typecheck
npm run build        # dist/
```

Структура:

```
src/
├── index.ts            сборка приложения и запуск
├── config.ts           переменные окружения
├── db/database.ts      SQLite: устройства, пары, расписания, события
├── lib/
│   ├── protocol.ts     типы конвертов и строгий разбор
│   ├── auth.ts         токены устройств
│   └── logger.ts       JSON-журнал с вырезанием секретов
├── routes/             HTTP API
└── ws/hub.ts           маршрутизация WebSocket
```

---

## Резервная копия

Всё состояние — один файл SQLite:

```bash
docker compose exec relay sh -c 'cat /data/pcmate.db' > pcmate-backup.db
```

Восстановление — положить файл обратно в том `relay-data` и перезапустить
контейнер.

---

## Обновление

```bash
git pull
docker compose build
docker compose up -d
```

Схема базы создаётся идемпотентно (`CREATE TABLE IF NOT EXISTS`), данные
переживают обновление.
